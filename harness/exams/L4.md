# 試験 L4：道具の改修

あなたは novel_studio の保守担当です。まず `AGENTS.md` を読み、そのうえで、この試験に限り `engine/tools/` のコードを直すことを許可します。

## 状況
- `INCIDENT.md` に、利用者から届いた不具合の報告が2件あります。
- 回帰テストは `python3 -m unittest discover -s engine/tests -v` です（偽モデルを自分で立てるので、費用もネットワークも要りません）。

## やること
1. テストを実行し、失敗を確かめる。
2. `INCIDENT.md` とテストの失敗から原因を突き止め、`engine/tools/` の中だけを直す。
3. テストがすべて通ることを確かめる。
4. `FIX_REPORT.md` に、不具合ごとに「症状／原因（ファイルと行）／直し方／確かめたこと」を書く。

## 守ること
- **テスト（engine/tests/）を書き換えない。** studio/ も変えない。
- 直す範囲は最小にする。関係のないリファクタリングをしない。
