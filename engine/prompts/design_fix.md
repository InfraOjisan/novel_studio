# やること
- 「前回のCANON」をもとに、修正指示の問題だけを直したCANON全体を出力してください。
- 【人の指示】と書かれた指示は、プロデューサーの決定です。最優先で反映してください。
- 問題のない部分は、できるだけそのまま残してください（仕組みや人物を作り直さない）。
- 一つ直したら、その事実を参照している箇所（時間表・人物・章カード・不変条件）もすべて同じ値にそろえてください。

# 出力形式
- 1行目は `# CANON` で始める。CANON以外は出力しない。コードブロックで囲まない。
