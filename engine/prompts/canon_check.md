# 確かめること

1. **日付と曜日・時間の流れ**：第1節の物語の期間と、章カードの「時期と場所」が合っているか。時間表の時刻どうし、時間表と不変条件、時間表と伏線スロットの時刻が合っているか。「明朝」「翌日」のような相対の言い方が、曜日と合っているか（金曜の夜の「明朝」は土曜）。
2. **数と回数**：「三回のみ」「二本」「7名」のような数が、時間表や人物一覧の実際の数と合っているか（発見者の入室など、数え漏れがないか）。
3. **物の所在と経路**：証拠・小道具が、ある場面ではA、別の場面ではBにあるとき、AからBへ動いた経緯が書かれているか。
4. **人物の属性**：年齢・背格好・呼び方・役職が、節どうしで食い違っていないか（「背が高い」と「中背」など）。
5. **秘密の扱い**：第11節の「本文に書かないこと」が、章カードや伏線スロットで明かす予定になっていないか。伏線の設置・補強・回収の章が、章カードと伏線スロットで一致しているか。
6. **現実の前提**：舞台に対して、制度・組織・地名の誤りがないか（東京都の警察は警視庁、など）。
7. **要旨と本体**：第0節の要旨が、第2節以下の仕組みと食い違っていないか（初動の見立て、死因、動機など）。

日付の機械検査の結果が渡されていれば、それも指摘に含めてください。
